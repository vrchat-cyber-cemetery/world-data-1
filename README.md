# Cyber Cemetery — World Data 1

本仓库只部署图文包256～511，不分配墓位或发放额度。

计划地址：<https://vrchat-cyber-cemetery.github.io/world-data-1/>。当前未配置Pages发布，没有已发布图文包。

- [主仓库及内容来源](https://github.com/vrchat-cyber-cemetery/vrchat-cyber-cemetery.github.io)
- [GitHub开发计划](https://github.com/vrchat-cyber-cemetery/vrchat-cyber-cemetery.github.io/blob/main/plans/GITHUB-DEVELOPMENT.md)
- [运行时协议](https://github.com/vrchat-cyber-cemetery/vrchat-cyber-cemetery.github.io/blob/main/plans/RUNTIME-DATA.md)

后续工作流从主仓库批准构建包下载产物，核对SHA-256后使用本仓库Token部署Pages。生成的.bin和压缩档案不反复提交到源码历史。

本地验证：Node.js24下执行 npm run check。自有代码采用[MIT](LICENSE)，包中纪念内容和图像保持各自授权。
